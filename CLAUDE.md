# Pero Launcher

Кастомный лаунчер Minecraft Java Edition на Electron. Только Windows.

## Как со мной работать (важно)

- Автор проекта **не знает языков программирования и не собирается их учить**.
  Код пишешь ты полностью. От автора — запуск команд, скриншоты, описание что видно на экране.
- Объясняй по-человечески: что делаем и зачем, без предположения что термины знакомы.
  Не разжёвывай интерфейс по кликам («нажми File → Open») — это не нужно. Нужно объяснение сути.
- Язык общения — **русский**.
- Идём не спеша, по одному шагу. Не вываливай десять задач разом.
- **Правь файлы сам**, точечно. Не проси автора вручную «замени этот блок» — на этом
  уже несколько раз ловили задвоенный код (два `require('electron')`, два `contextBridge`,
  дублированный `preload.js` целиком).
- Перед тем как сказать «готово» — проверь синтаксис (`node --check`).

## Стек и решения

- **Electron + чистый HTML/CSS/JS.** Выбран осознанно: у Tauri нет готовых библиотек
  под Minecraft (пришлось бы писать авторизацию и запуск с нуля на Rust), а C#/WinUI
  требует Visual Studio. Тут — только Node.js и готовые пакеты.
- `msmc` — авторизация Microsoft/Xbox (лицензионные аккаунты, игра на лицензионных серверах).
- `minecraft-launcher-core` — скачивание версий/библиотек/ассетов и запуск игры.
- Своего бэкенда нет и пока не нужно. Firebase — только если появятся аккаунты
  пользователей, облачная синхронизация или публичный каталог сборок.
- Сборка в `.exe` планируется через `electron-builder` (ещё не настроено).
  Пользователю финальной версии не нужен ни Node.js, ни npm — всё внутри exe.

## Дизайн

Плиточный, **без текста на главном экране** — только иконки. Референс — макет автора.

- Окно **frameless** (`frame: false`), свой тайтлбар: логотип + «Pero V1.0.0» слева,
  свернуть/развернуть/закрыть справа в **стиле Windows 10** (не 11).
- Кнопка «развернуть» меняет иконку: одиночный квадрат ↔ два перекрывающихся (restore).
  Состояние приходит событием `window-state` + запрашивается через `isMaximized()` при
  загрузке каждой страницы (иначе при переходе в развёрнутом окне иконка была неверной).
- **Никаких рамок и линий между плитками.** Никакой линии между тайтлбаром и сеткой.
- Кнопки управления окном и «назад» — **вплотную к краю окна**, без отступа.
  Отступ 10px только у логотипа, и он обнуляется правилом `.back-btn + .app-icon`.
- Всё кликабельное в тайтлбаре обязано иметь `-webkit-app-region: no-drag`,
  иначе клик уходит в перетаскивание окна (так «сломалась» кнопка назад).
- Hover на плитке: `scale(1.03)` + **более насыщенный оттенок того же цвета**.
  Не использовать `filter: saturate()` для приглушения — автор сказал, что от этого
  плитки выглядят «пластмассовыми».

### Сетка главного экрана

| позиция | цвет | назначение |
|---|---|---|
| колонка 1, ряд 1 | жёлтая | открыть папку игры в проводнике ✅ |
| колонка 1, ряд 2 | серая | настройки + менеджер версий и аккаунтов |
| колонка 2, ряд 1 | красная | браузер сборок/модов (Modrinth/CurseForge) ❌ |
| колонка 2, ряд 2 | белая | скин игрока (в будущем — падающие перья) ❌ |
| колонка 3, оба ряда | зелёная | запуск игры (большая панель со стрелкой Enter) ✅ |

### Настройки

Тот же плиточный стиль, страница **прокручивается** — не надо впихивать всё в один экран.
Сверху три широкие строки: Версия, Аккаунт, Память (ОЗУ). Ниже — сетка 2 в ряд.
Многое взято с Legacy Launcher.

- Флажок → тумблер/чекбокс в правой части ячейки.
- Ввод или выбор → по возможности **прямо в ячейке** (ОЗУ, размер окна),
  модалка поверх — только там, где иначе не влезает (фильтры версий, язык).
- ОЗУ: слайдер ограничен **реальным объёмом памяти системы** (`os.totalmem()`),
  режим «Авто» = половина ОЗУ, но не больше «всего минус 2 ГБ», округление до 512 МиБ.

## Локализация

Три языка: **русский, английский, немецкий**. Тексты — в `locales/*.json`.
В разметке ставится `data-i18n="ключ"`, `src/i18n.js` подставляет значение.
Захардкоженный текст в HTML недопустим — при добавлении новой надписи сразу заводи ключ
во всех трёх файлах.

## Пути и данные

- Папка игры: **`E:\.minecraft`** (существующая установка на диске E).
- Настройки лаунчера: `E:\PeroLauncher\settings.json` — намеренно **вне** `.minecraft`,
  чтобы не мусорить в папке игры.
- Пути пока жёстко прописаны в `main.js` (`settingsPath` и `defaultSettings.gameFolder`).
  **Перед релизом заменить** на универсальные (папка рядом с exe) — у пользователей
  диска E может не быть.

### Диск C не трогать (жёсткое правило)

На системном диске **мало места**. Ничего, что относится к проекту, игре или её данным,
не должно там появляться. Всё — на **E**.

- Папка `userData` Electron принудительно переведена на `E:\PeroLauncher\userdata`
  (`app.setPath('userData', ...)` в `main.js`) — иначе Electron складывал бы кэш и
  сессию авторизации в `C:\Users\<юзер>\AppData\Roaming`.
- Игра, ассеты, библиотеки, Java — только на E.
- Исключение, которое уже есть и живёт своей жизнью: кэш `npm`
  (`C:\Users\<юзер>\AppData\Local\npm-cache`) — создан самим npm, не проектом.
  Если место кончится — чистится командой `npm cache clean --force`.

## Известные грабли

- DevTools открываются автоматически (`openDevTools({ mode: 'right' })` в `main.js`).
  Шорткаты `Ctrl+Shift+I` и `F12` у автора **не работают**, поэтому оставлено так.
  **Убрать эту строку перед релизом.**
- `main.js` и `preload.js` не перечитываются на лету — после их правки нужен
  полный перезапуск `npm start` (Ctrl+C и заново).
- Первый запуск Minecraft качает ~300-500 МБ; повторные запуски используют кэш.
- Если Java не может выделить память при старте — снизить нижнюю границу (`min`).
  На этом уже падало с `insufficient memory` при `min: "2G"`.
- Автор один раз потерял проект из-за форматирования диска. Git заведён (локальный репозиторий),
  но `node_modules` в него не входит — после восстановления проекта нужен `npm install`.
