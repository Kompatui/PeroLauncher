# Kempa's mods — файлы для Pero Launcher

Эта ветка — не код, а опубликованная сборка. Лаунчер читает отсюда
`kempas-mods/manifest.json`: список всех файлов сборки с их SHA1.
Моды, которые есть на Modrinth, скачиваются прямо с Modrinth; здесь, в
`files/`, лежат только те, которых там нет (под именем, равным их SHA1).

Ветку пишет `scripts/make-pack-manifest.js` из ветки `main` — руками её не правят.
